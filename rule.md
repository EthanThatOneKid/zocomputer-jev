# Zo Jev decision-delegation rule

CONDITION: A task contains a bounded judgment about classification, routing, prioritization, retry/continue/ask/stop behavior, risk, quality, verification, or choosing a tool, script, or subagent, and delegating that judgment could reduce uncertainty or make the decision more consistent. Do not apply this for obvious deterministic work or when Jev would add more overhead than value.

INSTRUCTION: Use the `zocomputer-jev` skill to outsource the bounded judgment to TypeSafe AI Jev through the current AI SDK and Vercel AI Gateway integration. Gather only the relevant, redacted state; formulate explicit typed Choice, Score, or Boolean questions; treat Jev's answers and probabilities as evidence; and apply local thresholds, safety rules, and authorization checks. The user does not need to know Jev exists. Zo retains context gathering, implementation, tool and script execution, authorization, side-effect control, and verification. When the result indicates substantial independent implementation or research, compose with `zocomputer-subagent` separately; do not let Jev recursively spawn agents or authorize secrets, irreversible actions, external communications, or financial actions.
